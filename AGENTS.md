# Offline Vectora design files and agent skills

Agents may create complete, editable `.vectora` drawings offline and hand the file to the user to open in Vectora. Use the native **version-1 JSON document format**, with millimetre geometry; do not rename SVG/DXF or a Paper.js/history snapshot to `.vectora`.

## Skill routing

- Creating shapes/designs or editing a native file: read [vectora-design](skills/vectora-design/SKILL.md).
- Linting/repairing a design, or maintaining format tooling: read [vectora-design-lint](skills/vectora-design-lint/SKILL.md).
- Exact native fields and limits: [native format](skills/vectora-design/references/native-format.md). Simpler builder input: [recipe guide](skills/vectora-design/references/recipe.md).

The repository's `skills/` contains portable `SKILL.md` entrypoints. Harnesses can follow these links directly or install those folders into their own supported skills location; no harness-specific home paths are required. Scripts use Node 18+ and only its standard library, so authoring/linting works without a browser, app server, network or `npm install`.

## Build a design offline

1. Write a recipe with `format: "vectora-design"`, `version: 1`, `units: "mm"` and an `objects` array. Start from [the mounting-plate recipe](skills/vectora-design/assets/mounting-plate.design.json). The builder supports rectangles, circles, ellipses, regular polygons, lines, polylines, native Bézier paths and compound contours. All dimensions/points remain mm even when a canvas display unit is inches or centimetres.
2. Assign actual layer IDs/roles: `artwork`, `cutline`, `engrave`, `construction` (and existing raster vectors when relevant). Cuts are red `#FF0000`, engraving blue `#0000FF`, construction magenta `#FF00FF`; colour alone does not change operation. Paths normally remain unfilled. Put perforated-part contours into a compound when they should edit as one object; preserve holes with the intended fill rule. Closed contours use `closed: true`, without repeating the first anchor.
3. Build the native file, then lint it:

   ```sh
   node skills/vectora-design/scripts/vectora.mjs build design.design.json --out design.vectora
   node skills/vectora-design/scripts/vectora.mjs lint design.vectora
   ```

   Optional npm aliases: `npm run design:build -- ...`, `npm run design:lint -- ...`. Existing output is protected unless `--force` is explicit. `--json` exposes stable issue codes and JSON paths; `--strict` also fails on warnings. Lint is read-only. Exit codes: 0 passed, 1 design/JSON or strict-warning failure, 2 usage/filesystem failure.
4. Check the reported object count/bounds and intended dimensions; review warnings rather than changing the user's design to silence them. Deliver both `.vectora` and recipe files plus a short lint result. The ready-to-open [example](skills/vectora-design/assets/mounting-plate.vectora) is illustrative, not manufacturing guidance.
5. In Vectora use **File → Open** / **Ctrl or Cmd+O**, then choose the `.vectora` file. The current editor opens it in a new active document tab and retains existing tabs; it does not merge the geometry into the current drawing. No hosted upload service is needed. If the app is available, inspect and save/reopen the artifact before claiming an in-app round trip passed. Report when only offline checks were possible.

## Native-file invariants and lint maintenance

The authority is `src/documentFormat.ts`, not these docs or the standalone validator. Native objects are `path` or `compound`, with contours of `[x,y,inX,inY,outX,outY]` segments. Bézier handles are **relative vectors** to their anchors. Coordinates and actual curve extrema must stay within ±1,000,000 mm. Unique object IDs span all layers; object roles must agree with their layer. Set `rasterLayerInitialized: true` to avoid the legacy extra-layer migration. Store geometry in document coordinates with complete native style fields; there is no generic native object-transform field.

Limits: 50 MiB files, 1000 layers, 20000 objects, 50000 contours, 500000 segments. The linter checks schema, limits, bounds, editable-metadata structure and circular arc identity, and warns about open cuts, identical ordered process geometry, invisible/hidden geometry, off-canvas shapes and fields that may be discarded/normalized. It does not certify arbitrary curve intersections, reversed/reparameterized duplicates, font/annotation regeneration, wall thickness, kerf, machine settings or manufacturing suitability. Never flatten exact curves, close intentional slits or discard editable metadata merely to pass lint.

**Keep the design linter up to date in the same task as every relevant application change.** Changes to document serialization/import validation, supported geometry or editable metadata, layer roles, style/paint fields, fonts, units, grid/canvas settings, processing limits or export behavior used by lint warnings must include a review of `skills/vectora-design/scripts/lint.mjs`, its shared constants in `geometry.mjs`, and the recipe builder in `build.mjs`. Update affected validation rules, diagnostics and generation behavior together with regression tests, native-import parity checks, skill references and example files. Do not defer synchronization or leave the linter validating an older contract. If a relevant application change requires no toolkit changes, explain why in the task's verification summary.

When changing the native format, shape generation or linter:

```sh
npm run design:test
npx playwright test tests/offlineDesign.spec.ts --reporter=line
npm run build
```

Keep the recipe/native references, example artifacts and skill instructions synchronized with the implementation. Add meaningful malformed-input and real-import parity coverage for format changes. The portable Node tests live inside the skill kit; browser integration tests remain local under the existing repository test policy. If a harness has only a copied kit, run its Node tests and disclose that native-import parity was not checked. Do not weaken the app's validator to accommodate generated files. Creating local design artifacts does not itself authorize a commit, push, PR or external publication.

# UI and design-system synchronization

For every editor UI change, update `reference/design-system.html` in the same task so the reference reflects the current design. This is an explicit user requirement. Keep shared tokens, component CSS, icons, spacing, and relevant specimen markup synchronized with the application. Mirror the reference's style block in `src/design-system.css`; use `src/editor.css` for editor-specific integration rules. Update relevant reference descriptions when behavior or presentation changes. Do not leave the reference as a historical snapshot or defer its update.

Current toolbar layout: no Top / application tools, Left / drawing, or Right / properties captions. The File button displays only its folder icon, with no dropdown arrow. The left and right rails sit 24px from their respective workspace edges, and the top toolbar sits 24px from the top, including on smaller screens. Use the shared `--workspace-edge-inset` token for this spacing.

Canvas grid: fills the viewport edge to edge with no outer padding; only the floating controls retain their 24px inset. The grid uses a pale blue-white background and subtle blue-gray 1px lines, with a major line every five visible cells. Keep cells at least 24 CSS pixels apart using document-aligned whole-millimetre spacing (10 mm minor / 50 mm major at 100% zoom, down to 1 mm when zoomed in), shown in the footer. Origin lines use the same color and weight as other major grid lines, with no dark axis highlight. Shared grid colors live in the design-system tokens. Keep the reference grid specimen and documentation synchronized with any grid changes.

Footer: clicking the zoom percentage resets to 100% around the current view centre, preserving artwork, selection and history. Use a keyboard-accessible button with a reset tooltip. Keep the zoom/grid readout at the exact horizontal centre, independently of the left tool label and right navigation hint widths. Use equal flexible side columns, including when the right hint is hidden on small screens.

Snapping: the magnet in the left toolbar and shortcut S are a master switch for grid and object snapping, on by default. Preserve all individual mode choices while paused. Configure grid and object modes in Preferences → Snapping. Use the visible minor grid interval in document millimetres for drawing, movement, and resizing. Keep numeric entries exact and prioritize Shift aspect-ratio constraints.

Shapes: artwork and drawing previews have no fill, only charcoal strokes; cut lines remain unfilled red strokes. Keep artwork interiors selectable for dragging without introducing a visible fill.

Empty canvas: show the grid without welcome text, starting instructions, or a central text overlay.

Layers: use the shared Layers panel with its draggable header, count, 64px rows, layer markers (Artwork uses #383838 to match its strokes), expanders, visibility/lock controls, and footer. The editor starts with Cut Path, Engrave Path, Construction Path and Artwork. Add layer offers these four types, with automatic unique names; Raster Engrave is excluded. Delete confirms removal of the layer and its contents; locked layers cannot be deleted. Adding, deleting, moving, visibility and locking support Undo/Redo. Transfer objects by dragging them onto a layer row; annotations stay in Artwork-type layers. New drawing and tracing start in the default Artwork layer. Deleted default Artwork/Cut Path layers can be restored with Add layer. Engrave paths export on separate DXF layers, and Artwork requires Include artwork. Drag objects from expanded rows onto other visible, unlocked layers to transfer them; dragging a selected object moves the selection, while an unselected object moves alone. Valid targets have a white outline; cancelled drops make no changes. Holding a dragged object within 40px of the list’s top/bottom auto-scrolls only the list, faster toward the edge (up to 360px/s); leaving the edge, ending/cancelling the drag or losing focus stops scrolling. Transfers support Undo/Redo. Expanded rows list selectable document objects; keep Layers open when selecting an object. Hidden/locked layers cannot be edited; visibility only affects the canvas, not DXF export.

Menus: File, Shapes, Layers, Properties and reference settings/confirmation panels use the toolbar charcoal (#383838), white text, lighter secondary labels, grey dividers, and white selected rows with charcoal text. Scope the dark palette to floating surfaces; preserve the light grid. Keep field and button states readable in dark panels.

Shape tools: Rectangle (R), Circle (C), Ellipse (E), and regular Polygon (Y). Ellipse uses opposite bounding corners; Shift constrains a circle. Polygon uses centre-to-vertex dragging, with 3–64 sides (default 6) adjusted using Up/Down on canvas; the Shapes menu contains only shape choices; Shift constrains rotation to 15°. Snap polygon centre/radius rather than individual vertices to preserve regularity. Centre arc (A), in the separate Arcs pop-out below Lines, uses a centre-to-radius drag, creating an exact semicircle and switching to Select on release. Dedicated Move, Rotate, Sweep and Radius handles preserve circular geometry. Centre/radius snap in mm; angles magnet to 90° increments within 4°, with Shift for 15°. Properties includes Radius, Start, signed Sweep (±1–359°), Semicircle 180° and Flip arc. Single-arc width/height edits scale uniformly; nonuniform multi-selection transforms convert arcs to freeform paths. Escape/tool switching/focus loss cancels drawing or handle edits. Each edit is one undo step; arcs remain open/unfilled and support cut transfer and DXF.

Properties: opens only on an explicit Properties or Export DXF action. Creating or selecting a shape must not open it automatically; keep an already open panel open and update its fields for the current selection.

Multi-selection: Select-drag from empty canvas selects fully enclosed visible/unlocked shapes. Shift-drag adds; Shift-click toggles. Show a charcoal dashed marquee with a translucent blue fill using shared selection tokens, individual selected bounds, and shared resize handles. Move/resize/delete and Properties numeric edits apply to the combined selection as one undo step. Preserve Properties visibility. Outline creation requires a single selected shape.

Layer transfer: Drag artwork objects from expanded Layers rows onto Cut Path, including multi-selection. There is no separate Move button. Move the existing objects without offsetting/duplicating geometry, set their role to cutline and apply the same shared --color-cutline stroke as sticker outlines. Preserve selection, support one-step undo/redo, and disable transfers into hidden/locked Cut Path.

Lines menu: separate line icon below Shapes on the left rail, with Line (L), Polyline (P) and Freehand (F) in a charcoal pop-out. Line uses endpoint dragging; Polyline uses successive clicks, Enter/double-click to finish, Backspace to remove the last vertex and Escape to cancel. Snap endpoints in mm; Shift constrains 45° angles. Paths remain open and unfilled, select by stroke, support cut-layer transfer and open DXF export. Two-point paths have endpoint handles; handle zero width/height without invalid transforms. Sticker Outline is disabled for open paths.

Arcs menu: separate arc icon below Lines on the left rail. Centre arc (A) preserves the centre/radius semicircle workflow. Three-point arc (Shift+A) restores start → curve point → end clicks, snapped in mm, live preview, duplicate/collinear validation, Backspace and Escape cancellation. Three-point arcs use the original bounds handles and keep the tool active after completion. Both variants remain open/unfilled and support history, cut transfer and DXF. Arcs are not listed in Shapes.

Delete tools: separate eraser button below Arcs with Dissect delete (K) and Line delete (Shift+K). Dissect removes the section between existing path points or intersections, including rectangle edges, polygon sides, polyline segments and curved sections without crossings. Open closed outlines at the removed section and keep surviving runs connected. Single-segment paths can be removed entirely; empty clicks do nothing. Visible locked paths can define boundaries, hidden paths cannot. Line delete removes the whole clicked object including compound contours. Hover highlights deletion with --color-delete-preview, 5px stroke and 85% opacity; overlays never export. Click is one undo step, Escape returns to Select, Properties does not auto-open. Only visible/unlocked targets can change; cut paths work even when Artwork is locked. Trim exact Bézier curves in document space without snapping or flattening, preserve original layer/style, and clear stale parametric arc/polygon metadata.

Freehand (F): part of Lines. Press-drag-release creates one smooth, open, unfilled stroke with round caps/joins. Sample in document coordinates with screen-space spacing and gentle smoothing; preserve endpoints. Freehand drawing intentionally bypasses grid snapping and Shift constraints; later transforms use normal snapping. Keep previews out of document/export, ignore clicks without dragging, cancel on Escape/tool changes/pointer cancellation/focus loss, and commit once per stroke. Keep Properties closed, support selection, cut transfer, both delete tools and open DXF export.

Rotation: in Select, drag the round handle 28 CSS pixels above the selection bounds; Shift snaps to 15°. Rotate around the combined bounds centre for multiple objects; single circular arcs retain their existing centre-based Rotate handle. Properties offers absolute accumulated rotation degrees labelled R for one object (0–360°), or a relative By angle for multiple objects. Numeric angles bypass snapping. Maintain circular arc centre/start metadata, stroke style and layer membership; one drag/entry is one undo step. Escape, pointer cancellation and focus loss cancel. Properties does not auto-open. Bounds fields remain axis-aligned. Keep the rotation handle fixed 28 CSS pixels directly above the current axis-aligned selection box’s top centre, including during rotation. The connector stays vertical at that same attachment point as bounds change; it never travels around the box. Apply this to curves, flat lines and multi-selections.

Properties with no selection: opening the Properties toolbar button shows a centred sliders icon, “No selection” and “Select an object to inspect and edit its properties.” in the charcoal panel. Hide all editing and export options. Update live as selection changes; never auto-open. File → Export DXF explicitly opens export options even without a selection.

Floating selection menu: use a compact 40px-high shell, 32px grip/controls, 4px padding/gaps, 12px text and 16px icons. Show the shared charcoal pill only when one or more objects are selected, with the live selection count. Start bottom-centred above the footer. The grip supports dragging and arrow-key nudging (2px, Shift 10px); Escape cancels a move. Retain user placement across selection changes, clamp inside the workspace, and wrap on narrow screens. Close path, Join and Nest use 32px square icon-only buttons with accessible names and hover labels; Close path uses the shared i-close-path endpoint/closing-segment icon. Close path joins the nearest endpoints of selected open paths on the same layer, reversing paths as needed, and closes the final gap with a straight segment. A single open curve/polyline closes directly; a lone straight line cannot close. Preserve exact curves, existing closed contours, layer and style; merge coincident endpoints, clear arc/sides metadata, select the result and commit one undo step. Closed-only and mixed-layer open selections are disabled. Properties stays unchanged. Join combines two or more selected objects on the same layer into one compound shape, preserving exact contours, open/closed states and positions without adding connections or merging overlaps. Select via any component; move, resize, rotate, duplicate, transfer and delete as one. Flatten existing compounds when joining again. Keep layer/style, select the result, preserve Properties visibility and commit one undo step. Disable Join for single selections, mixed layers and active gestures. Nest remains a disabled placeholder.

Object snaps: configure modes in Preferences → Snapping; there is no toolbar pop-out. The magnet and S pause/resume all configured snapping together without resetting choices. Intersection, Nearest, Centre, Tangent and Perpendicular are individually opt-in, off by default. A 10 CSS pixel capture radius stays constant at every zoom; exact object geometry wins over grid rounding, with discrete construction points ahead of Nearest. Show a blue square and mode label using --color-object-snap. Visible locked objects can be references; hidden and currently transformed objects cannot. Tangent uses the current line start/polyline vertex against Bézier curves; Perpendicular projects onto finite straight segments. Drawing, moving and corner resizing support point snaps; Shift constraints take priority. Freehand, rotation, numeric entries and exports are unaffected. Clear previews on cancellation, finish, pan, zoom and pointer leave.

Preferences: the Settings gear opens the shared charcoal Preferences modal with General, Grid, Snapping, Appearance and Editing tabs. Use the reference shell, responsive sidebar, scrolling content and footer. Snapping contains live Enable snapping, Snap to grid, Intersection, Nearest, Centre, Tangent and Perpendicular switches. Changes apply immediately; the master magnet preserves mode choices. General, Grid, Appearance and Editing remain empty placeholders. No Reset preferences action or persistence. The footer identifies live changes vs placeholder tabs. Tab navigation, arrow keys, Escape and Close work, with modal focus containment and focus restored to Settings. Suppress canvas shortcuts while the dialog is open.

Duplicate selection: whenever a completed shape is selected, including immediately after creation with the drawing tool still active, show two overlapping 10px white squares with a 1px selection-colour outline, matching the rotation circle, within an invisible 28px click target.
